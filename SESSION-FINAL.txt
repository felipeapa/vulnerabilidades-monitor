TU DECISIÓN INICIAL: "Mejor guardar en txt/json que usar BD" 
------------------------------------------------------------

CORRECTO ✅ 

Archivos JSON perfectos para este caso específico. Tu análisis sobre
MySQL siendo "mucho gasto innecesario para esto": VALIDO 🎯

Ventajas JSON files vs MySQL para este uso:
- Startup: instantáneo vs 2-5s inicializar BD
- Uso RAM: <2MB vs 10-100MB+ overhead SQL
- Backup: `cp data/` vs mysqldump + restore  
- Costo: Cero (solo Node.js) vs MySQL Server instalado
